# 微更新影响评估方法与分析流程

本文档说明街道口袋空间改造、道路改善、社区服务点开放三类微更新的分阶段评估流程。
目标不是给出一个单一的"成效数字"，而是回答两个问题：**发生了什么变化**，以及
**这个变化在多大程度上可以归因于项目本身**。所有实现位于 `src/renewal_analytics/`，
仅依赖 Python 标准库。

## 1. 为什么不能直接做前后两期均值相减

朴素前后差 = 后期均值 − 前期均值，它同时包含四类成分：

1. 项目自身效应；
2. 季节波动（季度指标的周期性起伏）；
3. 人口迁移与片区边界变化导致的群体构成变化；
4. 同期其他措施（交通调整、住房保障等）的影响。

本流程把朴素前后差**保留为描述性结果**（明确标注"仅描述、不能单独归因"），
再通过对照组、双重差分和证据分级逐层剥离或标注上述混杂因素。

## 2. 数据口径与缺失处理

### 2.1 空值即缺失，绝不补零

CSV 中的空单元格统一解析为 `None`。任何 (片区, 期别) 指标缺失时：

- 该单元格不参与均值、前后差、DiD、区间等任何计算；
- 样本可用性表逐期列出有效样本数、缺失片区与缺失率；
- 若缺失导致某个估计量无法成立，该估计量返回"不可估计"及原因，
  对应结论降为 D 级（资料不足），而不是用 0 凑出一个数字。

### 2.2 迟到上报与事后修订（as_of 快照）

`area-periods.csv` 允许同一 (片区, 期别) 出现多份记录，以 `received_at` 最新一份
覆盖旧版。每次运行可指定 `--as-of YYYY-MM-DD`：

- 只纳入该日期之前（含当天）到达的数据，模拟"当时能看到什么"；
- 同一键取快照内最新版本；
- 运行结果连同 as_of 口径与输入文件 SHA-256 指纹一起落盘，旧分析可精确复现。

### 2.3 干预记录修订

`interventions.csv` 的 `revision_of` 指向被取代的旧记录。旧记录标记为
`superseded` 并保留审计，时间线只采用修订后的有效记录。

### 2.4 实际开放时间优先于计划

状态判定一律以 `actual_open` 为准；计划日期只用于推断施工期。两者落入不同季度时，
报告显式提示"计划 X、实际 Y，分期已按实际日期重算"。尚无实际开放日期的项目
不产生开放效应分析，只跟踪计划/施工状态。

## 3. 阶段时间线与对照组资格

### 3.1 状态矩阵（片区 × 期别 × 干预类型）

| 状态 | 含义 |
|---|---|
| `none` | 观察窗内无该类型干预 |
| `planned` | 有计划开工日但尚未开工 |
| `construction` | 已开工未开放；施工期影响单独描述，不计入开放效应 |
| `open` | 实际开放日所在季度及以后 |
| `unknown_timing` | 有记录但开工/开放日期均缺失，无法定位，排除出处理组与对照组 |

判定使用日期与季度边界的精确比较：开工日落入某季度时该季度即算施工期，
开放日落入某季度时该季度即算开放。

### 3.2 对照失效（censor）规则

对每个非处理片区按干预类型逐一审查：

- 窗口内出现同类型施工/开放：自事件期别起**审查退出**，之前期别仍可使用，
  报告写明失效期别与原因；
- 出现 `unknown_timing`：无法证明干净，整个窗口排除；
- 自身有同类型项目且仍停留在计划阶段：不列入对照候选（不能当自己的对照）；
- 全程 `none/planned` 且自身无项目：合格对照。

分批开放时采用 **not-yet-treated 对照**：每个开放队列只与"截至该队列开放期
仍未发生同类型事件"的片区比较，已处理片区永不回流为对照，从源头杜绝污染。

## 4. 估计量层级

### 4.1 朴素前后差（描述层）

处理片区自身的期别变化，始终展示但仅作描述。

### 4.2 双重差分 DiD（对照层）

```
DiD = (处理组后期均值 − 处理组前期均值) − (对照组后期均值 − 对照组前期均值)
```

对照组的同期变化代表共同趋势（季节、宏观因素等），相减后剩余部分才是
"在平行趋势假设下可归因于项目"的变化。四格中任一格无有效样本则 DiD 不可估计。
样本量允许时给出独立四格近似标准误与 95% 区间；每组每期不足 2 个片区时
诚实标注"无法估计抽样不确定性，仅给点估计"。

### 4.3 多批次队列估计（分批层）

按实际开放期别划分队列，逐队列做 DiD（前期=开放前一期，后期=开放当期），
再等权汇总，避免传统双向固定效应在分批设计下的负权重问题。无对照或无前期
基线的队列单列丢弃原因，不参与平均。

### 4.4 平行趋势检验

至少需要两个处理前期别：计算处理组与对照组的前期水平差与线性斜率差。
前期不足、缺失或斜率差相对处理后变化过大（经验阈值：超过 DiD 点估计的一半）时，
结论不得给 A 级。

### 4.5 人口构成：总体变化 vs 同类居民变化

基于 `area-history.csv` 的边界版本：

- **范围断裂（scope break）**：前后期别适用版本不同、区块集合增减时，
  片区总量前后差含新增/流失区块，禁止直接参与趋势计算；
- **持续区块分解**：两期共同覆盖区块上的人口变化才是"同类居民变化"，
  新增/流失区块人口单列；
- **数量/强度分解**（计数指标）：`Δ总量 ≈ 强度效应 + 规模效应 + 交互项`，
  区分"同等居民使用率提高"与"人多了所以用量多"。

### 4.6 同期其他措施

落在比较窗口内的措施按落点分两类：

- **非对称措施**：只影响处理组或只影响对照组 → DiD 无法剥离，结论上限 C 级；
- **共同措施**：两组都受影响 → DiD 可扣除其共同部分，报告保留提示，
  但其特异性影响仍需分析人员留意。

## 5. 证据分级（结论强度的唯一口径）

| 级别 | 名称 | 条件 | 允许的表述 |
|---|---|---|---|
| A | 可信对照 | 有效对照、DiD 可估计、≥2 期前期且平行趋势无明显背离、无非对称同期措施、样本齐全 | 可作因果表述，必须附区间与依据 |
| B | 对照倾向 | 具备有效对照与 DiD，但平行趋势无法检验/背离、对照偏少等 | 有条件因果推断，注明限制 |
| C | 仅相关 | 无合格对照（全部审查/排除）或存在非对称同期措施 | 只报告相关与描述性变化，禁止因果数字 |
| D | 资料不足 | 干预时间未知、基线缺失、DiD 样本缺口等 | 不输出效应数字，只列缺口与补数建议 |

关键原则：**资料不足或对照失效时系统只能降级并说明原因，不允许输出确定性的
因果数字。** 降级路径（如 A→B）在报告中显式标注。

## 6. 版本留痕、复现与并列对比

每次运行写入 `runs/<run_id>/`：

- `result.json`：完整结论包（含输入指纹、as_of、全部中间结果与分级原因）；
- `manifest.json`：运行元数据；
- `report.md`：中文报告。

- `reproduce`：按旧 manifest 的 as_of 重跑并核对指纹；指纹变化时明确警告
  "输入已变更"，新结果与旧结论并列，绝不覆盖；
- `compare`：逐 (干预类型, 指标) 对比两个版本的分级、DiD 点估计与区间，
  标记分级是否变化、观察窗是否变化。

## 7. 命令行用法

```bash
# 一次完整分析（默认使用全部已到达数据）
PYTHONPATH=src python -m renewal_analytics.cli run --data data --runs runs

# 按历史时点复现"当时的分析"
PYTHONPATH=src python -m renewal_analytics.cli run --data data --runs runs \
    --as-of 2026-08-31 --run-id aug-snapshot

# 按旧 manifest 复现并核对输入指纹
PYTHONPATH=src python -m renewal_analytics.cli reproduce \
    --manifest runs/<id>/manifest.json --data data --runs runs

# 新旧版本并列对比
PYTHONPATH=src python -m renewal_analytics.cli compare \
    --old runs/<id1> --new runs/<id2> --runs runs

# 从已保存运行重新输出报告
PYTHONPATH=src python -m renewal_analytics.cli report --run runs/<id>
```

## 9. 已知限制（随数据积累可解除）

1. 观察窗只有两个季度时无法检验平行趋势，所有对照结论上限为 B 级；
   补入历史季度后重跑即可升级，无需改代码。
2. 单片区处理组无法估计抽样方差，只给 DiD 点估计；增加处理片区后自动产出区间。
3. 人口分解基于区块级人口，指标本身仍是片区级口径，无法做区块级率的标准化；
   若后续提供区块级指标，可在 `population.py` 基础上扩展直接标准化。
4. 平行趋势的斜率差阈值（DiD 的 1/2）是经验规则，正式研究可用假设检验替代。
